# Explorer page (source)

The app is one offline HTML file, `src/llm_lab/assets/explorer.html`, generated from this folder.
It has four pages, switched by the URL hash: **Architectures** (`#architectures`, or a tab such as
`#mla`) and placeholders for **Multimodal**, **Reasoning** and **Agents**. A new page is a
`<div class="page" data-page="…">` in `template.html` plus a link in `.pages`.

| File | What it holds |
|---|---|
| `src/content.js` | Model dimensions, all text and TeX, cache arithmetic, the decoding methods. Data and pure functions, no DOM. |
| `src/app.js` | Diagrams, pop-ups, step cards, tour, pages, keyboard handling. |
| `src/template.html` | Markup and CSS (light and dark). |
| `src/examples.json` | The example inputs: sentence, candidate next tokens with illustrative logits, beam-search second steps. |
| `src/tokens.json` | `examples.json` plus each model's real tokenization of it. Generated by `scripts/make_tokens.py`. |
| `build.mjs` | Checks every TeX string with Temml, subsets the math font, inlines everything into one file. |

## Build

```bash
cd web
npm install                       # temml
pip install fonttools brotli      # font subsetting
MATH_FONT=/path/to/latinmodern-math.otf npm run build
cd .. && python -m pytest tests/test_explorer.py tests/test_explorer_browser.py
```

`MATH_FONT` defaults to the TeX Live location
(`/usr/share/texmf/fonts/opentype/public/lm-math/latinmodern-math.otf`).

## Example inputs

After editing `src/examples.json`:

```bash
TOK_DIR=<folder with the @lenml/tokenizer-* npm packages> \
DEEPSEEK_LLM_GGUF=<llama.cpp models/ggml-vocab-deepseek-llm.gguf> \
python3 scripts/make_tokens.py
```

It uses `@lenml/tokenizer-{gpt2,gemma,qwen2_5,qwen3,deepseek_v3}` (ports of the Hugging Face
tokenizers) and, for DeepSeek-V2-Lite, byte-level BPE over llama.cpp's DeepSeek LLM vocabulary
(`scripts/bpe_gguf.py`). It refuses a candidate that is not a single token for every model, and a
sentence longer than the diagram's 10 rows.

## Rules the content follows

- Every dimension comes from the model's published `config.json`; the tests check the page against
  `llm_lab.reference.config`.
- No weights are loaded. Next-token logits, beam-search second steps and the speculative-decoding
  draft are illustrative and labeled, unless a bundle from `llm_lab.next_token` is embedded.
- Attention weights, index scores, expert choices and gate values in the diagrams are schematic.
- Cache sizes assume 16-bit values.
